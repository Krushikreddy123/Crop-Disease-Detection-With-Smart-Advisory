# 🌱 Crop Disease Detection and Farmer Advisory System

A deep learning-based system that detects crop diseases from leaf images and provides actionable farmer advisory.

## ✨ Features

* 🌿 **Crop Disease Detection** using CNN and TensorFlow
* 🔍 **Two-Stage Detection** — healthy/diseased → specific disease
* 🔥 **Explainable AI** using Grad-CAM heatmaps
* 📊 **Disease Severity & Progression** estimation
* 🧑‍🌾 **Farmer Advisory** — causes, treatments, organic alternatives, prevention, and spraying time
* 🌐 **Multilingual & Voice Support**

## 🛠️ Technologies

**Python · TensorFlow · CNN · Grad-CAM · Flask · HTML · CSS · JavaScript · OpenCV · NumPy**

## 🚀 Run Locally

```bash
git clone https://github.com/Krushikreddy123/Crop-Disease-Detection-With-Smart-Advisory.git
cd Crop-Disease-Detection-With-Smart-Advisory
python app.py
```

## 🎯 Objective

To help farmers identify crop diseases at an early stage and provide understandable, actionable recommendations for disease management.
